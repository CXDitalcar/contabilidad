# Contabilidad · Ditalcar

Página puente de la interfaz **Contabilidad** de DitalApp. El código de la interfaz vive en
[CXDitalcar/AppDitalcar](https://github.com/CXDitalcar/AppDitalcar) (mismo ingreso, misma API y mismo Storage);
este repo solo redirige a `https://yellow-mud-0e8164e10.7.azurestaticapps.net/contabilidad`.

- Acceso: Jefatura y Gerencia de Administración, y Experiencia/PM.
- Primera etapa: listas de precio de marca y bonos por cobrar por NV.

Para publicar la página: Settings › Pages › Deploy from a branch › `main` / root.
